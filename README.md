# fetch-test

Тестовая ветка HdRezkaPlus. Релизных файлов тут нет — только эксперименты.

## Файлы

- `RezkaPlus Fetch Test.user.js` — тестовый плеер: fetch шелла `iframe.cloud` через прокси с ретраем, чтобы побороть «Нет плееров».

## Установка

1. Tampermonkey → «Добавить новый скрипт».
2. Вставить содержимое `RezkaPlus Fetch Test.user.js` целиком.
3. Сохранить, открыть любой фильм на Rezka.

## Тест

- Плеер появляется со статусом «Поиск плееров...», при успехе мигнёт «С КАЙФОМ!».
- Кнопка ↻ — перезапустить поиск, если плеер не завёлся.
- Логи смотреть в консоли браузера (`Fetch test: ...`).

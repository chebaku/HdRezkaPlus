# HdRezkaPlus

> Когда стандартный плеер бесит, а любимый сериал ждать не собирается — HdRezkaPlus подключает альтернативный iframe.cloud плеер и чистит страницу от визуального хлама, как хороший антипохмелин после бурной вечеринки с рекламой.

## Установка

**[Нажми сюда для установки](https://raw.githubusercontent.com/chebaku/HdRezkaPlus/master/HdRezkaPlus.user.js)**

Требуется расширение [Tampermonkey](https://www.tampermonkey.net/) (или аналоги: Greasemonkey, Violentmonkey). При переходе по ссылке Tampermonkey автоматически предложит установить скрипт.

## Сценарии использования

- **Основной плеер не грузится** — HdRezkaPlus подставляет iframe.cloud плеер в обход встроенного.
- **Много рекламы и виджетов** — скрипт автоматически вырезает соцсети, VK-виджеты и рекламные блоки.
- **Узкая вёрстка контента** — после очистки страница растягивается на всю ширину экрана.
- **Смена источника** — кнопка ↻ в заголовке плеера позволяет перезагрузить iframe без обновления всей страницы.

## Как работает

1. **Очистка страницы** (`cleanAndStretch`) — удаляет VK-виджеты, рекламные блоки, элементы соцсетей по селекторам `#vk_groups`, `#vk_widget`, `.b-sharing-social` и другим. Затем растягивает таблицу контента `.b-content__columns` на 100% ширины.

2. **Внедрение плеера** (`injectPlayer`) — находит скрытую ссылку вида `/help/aHR0cHMlM0ElMkYlMkZ3d3cua2lub3BvaXNrLnJ1...`, декодирует из неё ID фильма с Кинопоиска, и вставляет контейнер с плеером `iframe.cloud/iframe/<id>` сразу после стандартного плеера Rezka. Плеер грузится через прокси `proxy4.rte.net.ru`.

3. **Перезагрузка плеера** — иконка ↻ в шапке контейнера перезагружает iframe с анимацией вращения, без перезагрузки всей страницы.

4. **Отслеживание DOM** — `MutationObserver` следит за изменениями на странице (динамическая подгрузка контента на Rezka) и повторно запускает очистку и внедрение плеера при необходимости.

# HdRezkaPlus

> Подписка на Rezka — это как платить за воздух в парке аттракционов: без неё вдохнуть не дают, а с ней — тот же самый воздух, только дороже. HdRezkaPlus исправляет это недоразумение, подсовывая под основной плеер - iframe.cloud, раздвигая турникеты визуального мусора.

## Установка

Потребуется расширение [Tampermonkey](https://www.tampermonkey.net/) (или аналог: Greasemonkey, Violentmonkey). После его установки:

**[Нажми сюда для установки скрипта](https://raw.githubusercontent.com/chebaku/HdRezkaPlus/master/HdRezkaPlus.user.js)**

Tampermonkey сам подхватит ссылку и предложит установить скрипт в один клик.

## Сценарии использования

- **Обход подписки** — основное назначение: HdRezkaPlus встраивает iframe.cloud плеер под основной плеер Резки, позволяя смотреть контент без оформления платной подписки Rezka.
- **«Нет плееров»** — скрипт догружает шелл плеера с ретраем, дожидаясь появления доступных источников.
- **Лишние виджеты и реклама** — скрипт автоматически вырезает соцсети, VK-виджеты и рекламные блоки.
- **Узкая вёрстка** — после очистки страница растягивается на всю рабочую ширину экрана.
- **Смена источника** — кнопка ↻ в заголовке плеера перезагружает iframe без обновления всей страницы.

## Как работает

1. **Очистка страницы** (`cleanAndStretch`) — удаляет VK-виджеты, рекламные блоки, элементы соцсетей по селекторам `#vk_groups`, `#vk_widget`, `.b-sharing-social` и другим. Затем растягивает таблицу контента `.b-content__columns` на рабочую ширину сайта.

2. **Получение ID фильма** (`injectPlayer`) — находит скрытую ссылку вида `/help/aHR0cHMlM0ElMkYlMkZ3d3cua2lub3BvaXNrLnJ1...` и декодирует из неё ID фильма с Кинопоиска.

3. **Загрузка шелла плеера** (`fetchShell`) — скачивает HTML `iframe.cloud/iframe/<id>` через прокси с ретраем (до 10 попыток с растущей задержкой), пока в ответе не появятся доступные источники `#cinemaplayerItems`.

4. **Внедрение плеера** — полученный HTML вставляется в iframe через `srcdoc` сразу после стандартного плеера Rezka. В шапке отображается статус загрузки, кнопка ↻ перезапускает поиск источников.

5. **Отслеживание DOM** — `MutationObserver` следит за изменениями на странице (динамическая подгрузка контента на Rezka) и повторно запускает очистку и внедрение плеера при необходимости.

- `rezka.ag`

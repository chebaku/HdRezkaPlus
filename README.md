# HdRezkaPlus

> Подписка на Rezka — это как платить за воздух в парке аттракционов: без неё вдохнуть не дают, а с ней — тот же самый воздух, только дороже. HdRezkaPlus исправляет это недоразумение, подсовывая плееру iframe.cloud и раздвигая турникеты визуального мусора.

## Установка

Потребуется расширение [Tampermonkey](https://www.tampermonkey.net/) (или аналог: Greasemonkey, Violentmonkey). После его установки:

**[Нажми сюда для установки скрипта](https://raw.githubusercontent.com/chebaku/HdRezkaPlus/master/HdRezkaPlus.user.js)**

Tampermonkey сам подхватит ссылку и предложит установить скрипт в один клик.

## Сценарии использования

- **Обход подписки** — основное назначение: HdRezkaPlus встраивает iframe.cloud плеер, позволяя смотреть контент без оформления платной подписки Rezka.
- **Лишние виджеты и реклама** — скрипт автоматически вырезает соцсети, VK-виджеты и рекламные блоки.
- **Узкая вёрстка** — после очистки страница растягивается на всю ширину экрана.
- **Смена источника** — кнопка ↻ в заголовке плеера перезагружает iframe без обновления всей страницы.

## Как работает

1. **Очистка страницы** (`cleanAndStretch`) — удаляет VK-виджеты, рекламные блоки, элементы соцсетей по селекторам `#vk_groups`, `#vk_widget`, `.b-sharing-social` и другим. Затем растягивает таблицу контента `.b-content__columns` на 100% ширины.

2. **Внедрение плеера** (`injectPlayer`) — находит скрытую ссылку вида `/help/aHR0cHMlM0ElMkYlMkZ3d3cua2lub3BvaXNrLnJ1...`, декодирует из неё ID фильма с Кинопоиска, и вставляет контейнер с плеером `iframe.cloud/iframe/<id>` сразу после стандартного плеера Rezka. Плеер грузится через прокси `proxy4.rte.net.ru`.

3. **Перезагрузка плеера** — иконка ↻ в шапке контейнера перезагружает iframe с анимацией вращения, без перезагрузки всей страницы.

4. **Отслеживание DOM** — `MutationObserver` следит за изменениями на странице (динамическая подгрузка контента на Rezka) и повторно запускает очистку и внедрение плеера при необходимости.

# TEST

Тестовая ветка HdRezkaPlus. Содержит улучшенное удаление рекламы (v1.3) перед заливкой в `master`.

## Что тестируем

- Баннеры brand-системы Резки (`[id^="brnd"]`, 250px-баннер в `.b-content__main`, пустой плейсхолдер).
- Сброс `padding-top` у `body` при `has-brand` — чтобы шапка подтягивалась к верху после удаления верхнего баннера.
- Баннер скачивания приложения (`.wide.b-dwnapp`).
- ВК-виджет целиком (`.vk-group`).
- Шапка плеера переименована в `HDREZKA PLUS`.

## Установка

Требуется [Tampermonkey](https://www.tampermonkey.net/). Открой ссылку:

**[Установить тестовую версию](https://raw.githubusercontent.com/chebaku/HdRezkaPlus/TEST/HdRezkaPlus.user.js)**

## Проверить

- Открыть любой фильм на Rezka — сверху не должно быть пустого зазора, контент не уезжает под шапку.
- Шапка уезжает вверх при скролле (не фиксированная).
- Внизу страницы не остаётся плашки ВК-виджета.
- Плеер `HDREZKA PLUS` встраивается и играет.
